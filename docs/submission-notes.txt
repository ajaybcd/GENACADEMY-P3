WEEK 3 PROJECT DOCUMENTATION DRAFT

Project overview
Code Review Workbench helps engineers review Python pull requests in Streamlit.
Three specialists investigate correctness, security and missing tests using
dynamic tool loops. The orchestrator validates evidence and produces a ranked
report. A person approves selected findings before a GitHub review is posted.

Architecture
PR URL -> bounded GitHub snapshot at a pinned commit -> Correctness specialist
-> Security specialist -> Tests specialist -> deterministic validation and
ranking -> LangGraph human interrupt -> selected findings -> guarded post.
Each specialist can alternate between model decisions and focused tools rather
than following a fixed analysis pipeline. Specialist execution is sequential to
keep shared call limits and failure behavior easy to inspect.

Data and evaluation
The built-in demonstration uses synthetic Python fixtures for SQL injection,
division by zero, and missing edge-case tests. It is for interface verification.
The three real evaluation cases, their PR URLs, exact commits, expected issues,
false positives and observed runtime must be recorded after live testing.
Do not represent fixture outputs or scripted-model tests as live evaluation.
Live analyses are now recorded for psf/requests PRs #6767, #6963 and #7502.

Exact commits, run IDs, traces and limitations are in docs/reports/real-1.json,

Runtime, precision, recall and false positives have not been measured or labeled.

3. Added GitHub snapshot loading, specialist tool loops, evidence validation,
   checkpointed human approval, and a per-run posting ledger.
4. Added behavioral tests and Streamlit interaction tests. Actual pass results
   and remaining limits belong in VERIFICATION.txt after the checks complete.
5. Fixed the native OpenAI tool-loop request by using Responses with explicit low
   reasoning effort. Added credential-safe diagnostics and model access checks.

   full-file search, path discovery, bounded directory search and shared pinned
   caching. All 42 regression tests passed. Live runs retained coverage limits.
